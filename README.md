# СТОКТРАК — MVP лидогенератора

Рабочий статический прототип на тренировочной выгрузке ГПБА от 05.05.2026.

## Что уже работает
- каталог из 1600 очищенных позиций: 744 тягача и 856 самосвалов;
- фильтры по типу, марке, году, цене, колёсной формуле и федеральному округу;
- поиск по бренду/модели/лоту;
- сортировки;
- карточка машины с данными состояния, документами и ссылкой на фото/видео;
- deep-link на лот через `?lot=XXXXXX`;
- две лид-воронки: конкретная машина и подбор под бюджет;
- SEO-слой с запросами «изъятка тягачей», «изъятка самосвалов», «лизинговая изъятка»;
- позиции с пометкой «не актуально» автоматически исключены;
- индикатор «ниже медианы стока» считается внутри одинаковой модели, если есть достаточно сравнений.

## Лиды
Сейчас заявки сохраняются в `localStorage`, чтобы MVP работал без сервера. Для production в `index.html` задайте endpoint в `CONFIG.leadEndpoint`.

## Важно
Текущая публикация использует тренировочный срез от 05.05.2026. Перед запуском платного трафика необходимо загрузить свежий сток, подтвердить публичность цен/фото и подключить CRM/аналитику.
