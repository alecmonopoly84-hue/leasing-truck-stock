# СТОКТРАК

Боевой статический сайт лидогенерации для тягачей и самосвалов из лизинговых стоков.

## Что реализовано
- каталог на 1 600 позиций;
- фильтры по типу, марке, году, цене, колёсной формуле и локации;
- карточка лота с модификацией, маскированным VIN, ПТС, ключами и комментарием по состоянию;
- коммерческая логика без внутренних/demo формулировок;
- основной контактный канал: `8 800 227 35 700`;
- мобильные CTA;
- SEO: index/follow, canonical, robots.txt, sitemap.xml, посадочные под «изъятка тягачей» и «изъятка самосвалов»;
- юридический дисклеймер агентского сервиса.

## Осознанно не реализовано
- фотографии в карточках: оставлены плейсхолдеры до загрузки нормальных изображений;
- форма обратного звонка/CRM: без безопасного серверного endpoint сайт не имитирует отправку заявки. Конверсия сейчас ведётся через телефон.

## Обновление стока
Публичные данные хранятся в сжатых частях `data/stock-part-*.txt`, которые загружает `index.html`.

## GitHub Pages
Публикация идёт автоматически из `main` через `.github/workflows/pages.yml`.
